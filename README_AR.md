# أطلس الباز الذكي لرؤية الهلال — ALBAZ Smart Crescent Visibility Atlas

حزمة الموقع الرسمي لـ **أطلس الباز الذكي لرؤية الهلال** (ALBAZ Smart Crescent Visibility Atlas)، مدعوم بمعيار ALBAZ-NE V2.2، وجاهزة للنشر على GitHub Pages.

## الملفات
- `index.html` — الصفحة الرئيسية الكاملة.
- `ALBAZ_NE_V2_2_USER_GUIDE_AR.html` — دليل استخدام عام مبسط، بلا تفاصيل النموذج الرياضي أو الخوارزميات.
- `site.webmanifest` — إعدادات PWA.
- `sw.js` — تخزين Offline بعد الزيارة الأولى عبر HTTPS.
- `.nojekyll` — يمنع معالجة Jekyll غير الضرورية.

## طريقة النشر
1. أنشئ مستودع GitHub جديدًا.
2. ارفع **كل الملفات الموجودة في هذه الحزمة إلى جذر المستودع**؛ لا ترفع مجلد الحزمة نفسه.
3. افتح `Settings → Pages`.
4. اختر `Deploy from a branch`.
5. اختر الفرع `main` والمجلد `/(root)` ثم Save.
6. انتظر ظهور رابط GitHub Pages.

الصفحة لا تحتاج خادمًا خلفيًا، والملف `index.html` ذاتي الاحتواء في المحرك والخرائط الأساسية.
